# 🀄 Авто-Маджонг

Маджонг-пасьянс с автомобильными эмблемами: Vue 3 + Vite на фронте, Express + MongoDB на бэке.

## Что есть в игре

- **4 режима**
  - 🀄 **Классика** — собираете все пары, время идёт вверх.
  - ⏱️ **На время** — обратный отсчёт (6/8/10 минут в зависимости от сложности), каждая пара даёт +5 секунд.
  - 🍃 **Дзен** — без таймера и проигрышей: тупики перемешиваются сами, а если позицию уже не спасти — ходы тихо откатываются.
  - 📅 **Вызов дня** — одна и та же раскладка для всех игроков в течение дня, отдельная таблица лидеров.
- **3 раскладки** — Черепаха, Пирамида, Крепость (по 144 плитки).
- **3 уровня сложности** — 18, 24 или 36 разных марок.
- **Гарантированно решаемые раскладки** — плитки раскладываются «с конца», так что решение всегда существует. Перемешивание тоже старается сохранить решаемость.
- **Карточка игрока** — имя, аватар-эмблема, уровень и опыт, статистика (партии, победы, серии, собранные пары, время в игре), личные рекорды и 10 достижений. Хранится в `localStorage`.
- **Таблица лидеров** по режиму, раскладке и сложности.
- Подсказки, отмена хода, «сыграть заново», подсветка свободных плиток, звуки, анимации, адаптив под телефон.

### Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Z` / `Ctrl+Z` | Отменить ход |
| `H` | Подсказка |
| `S` | Перемешать |
| `R` | Сыграть раскладку заново |
| `N` | Меню / новая игра |
| `L` | Таблица лидеров |
| `P` | Карточка игрока |
| `F` | Подсветка свободных плиток |
| `M` | Звук вкл/выкл |
| `?` | Правила |
| `Esc` | Снять выделение / закрыть окно |

Работают и в русской раскладке.

## Запуск

Нужны Node.js 18+ и MongoDB.

### Бэкенд

```sh
cd backend
npm i
npm start
```

По умолчанию подключается к `mongodb://localhost:27017/mahjong` и слушает порт `5000`.
Можно переопределить через переменные окружения `MONGO_URI` и `PORT`.

### Фронтенд

```sh
cd frontend
npm i
npm run dev
```

Адрес API задаётся переменной `VITE_API_URL` (по умолчанию `http://localhost:5000`).
Сборка для продакшена: `npm run build`.

## API

- `POST /add_result` — `{ name, time, reshuffles, hints?, difficulty, mode?, layout?, day? }`
  - `difficulty`: `easy` | `medium` | `hard`
  - `mode`: `classic` (по умолчанию) | `timed` | `daily`
  - `layout`: `turtle` (по умолчанию) | `pyramid` | `fortress`
  - `day`: `YYYY-MM-DD`, обязателен для `daily`
- `GET /users?difficulty=&mode=&layout=&day=` — топ-10 по времени.

Старые результаты без `mode`/`layout` считаются «Классикой» на «Черепахе».
